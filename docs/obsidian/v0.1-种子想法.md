# v0.1 — 种子想法：AI 三模式系统

> 一切的原点。StarChain 的祖先。

（完整内容见 Obsidian：`做/Hermes多模式切换改造/v0.1-种子想法-三模式系统.md`）

## 核心思路

AI 使用分三种模式：**聊天（Chat）→ 计划（Plan）→ 指令（Act）**。

| 模式 | 用途 | 模型 | 工具 |
|------|------|------|------|
| Chat | 探索、对齐、讨论 | 便宜模型 | web/search |
| Plan | 产出标准指令 | 中档模型 | read-only + 写计划 |
| Act | 执行 | 旗舰模型 | 全开 |

```
Chat（讨论需求）
  ↓
Plan（出方案文档）
  ↓
Act（按方案执行）
```

这个三段式模式最终演变为 StarChain 的三 Agent 协作。
